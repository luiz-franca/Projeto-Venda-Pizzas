Executar comando dentro do container(source do mysql)
docker exec -i devcontainer-mysql-1 mysql -u root -p<senha> < nome_do_banco < script.sql

O nosso seria algo assim(não deu certo):
docker exec -i devcontainer-mysql-1 mysql -u root -proot ../Web/sql/dump-dbselfpaypizzas-202505200937.sql

1. Copie o arquivo .sql para dentro do container

docker cp script.sql <nome_ou_id_do_container>:/script.sql

No nosso sistema(deu certo):
docker cp ../Web/sql/dump-dbselfpaypizzas-202505200937.sql devcontainer-mysql-1:/dump-dbselfpaypizzas-202505200937.sql

2. Acesse o container com o MySQL

docker exec -it <nome_ou_id_do_container> bash
3. Conecte ao MySQL no container

mysql -u root -p
Digite a senha quando solicitado.

4. Execute o arquivo .sql com source
Dentro do prompt do MySQL, rode:

source /script.sql;

No nosso caso(deu certo):
